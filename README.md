## Learning Objectives

By completing this course, I want to strengthen my ability to:

- Connect Power BI to Excel, CSV, SQL databases, and other sources.
- Profile, clean, and transform datasets using Power Query.
- Understand and write Power Query **M** expressions.
- Build dimensional models with fact tables, dimensions, and relationships.
- Create calculated columns, calculated tables, and measures using **DAX**.
- Understand row context, filter context, and `CALCULATE()`.
- Design clear, interactive reports and dashboards.
- Analyze business performance using KPIs and time intelligence.
- Publish, share, refresh, and secure Power BI content.
- Translate business questions into actionable data insights.
- Prepare for the **PL-300** exam using hands-on practice and mock assessments.

## Project 2 — Inventory & Profitability Analytics

**Difficulty:** Intermediate | **Status:** Not Started

**Business problem:** A store needs to reduce stockouts and monitor profitability.

**Objectives:**

- Model products, purchases, and sales
- Calculate sales, cost, and gross profit
- Identify slow-moving products and low-stock items
- Add interactive category and date filters

# Useful DAX Patterns

## Basic aggregations

```dax
Total Sales = SUM(Sales[SalesAmount])

Total Quantity = SUM(Sales[Quantity])
```

## Safe ratio

```dax
Profit Margin % = DIVIDE([Gross Profit], [Total Sales])
```

## Filtered calculation

```dax
Online Sales = CALCULATE(
    [Total Sales],
    Sales[Channel] = "Online"
)
```

## Year-over-year growth

```dax
YoY Growth % = DIVIDE(
    [Total Sales] - [Sales LY],
    [Sales LY]
)
```

> Examples are templates. Adjust table and column names for each dataset.
